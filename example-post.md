# How to write a blog post (delete this text and write your own)

Write normally, in plain text. Leave one empty line between paragraphs.

## Use two # signs for a section heading

Use **two stars** for bold text and *one star* for italic text.

- A line starting with a dash becomes a bullet point
- Another bullet point

1. A line starting with a number becomes a numbered list
2. Second item

> A line starting with > becomes a highlighted note.

To add a picture, upload the image to GitHub (for example site-photo.jpg) and write:
![Short description of the picture](site-photo.jpg)

To add a table:

| Pile length (m) | Capacity (kN) |
|---|---|
| 18 | 850 |
| 24 | 1200 |

To add a link: [ES Lab website](https://example.com)
