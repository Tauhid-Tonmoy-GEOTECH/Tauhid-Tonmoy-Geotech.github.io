# Personal website — how to update

All text is in content.js. Edit it on GitHub (pencil icon), then click Commit changes. Changes appear in 1–10 minutes; use a private window to see them sooner.

- LinkedIn: paste your profile link into linkedin: "" in content.js.
- Blog post: write a .md file (see example-post.md), upload it, then add a block in the blog list of content.js with the same slug (the file name without .md) and show: true.
- Report or observation: upload the PDF, then add a block in the documents list of content.js with file: set to the exact PDF name and show: true.
- Hide anything: set show: false.
